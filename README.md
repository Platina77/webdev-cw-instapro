# Instapro

MVP социальной сети для обмена фотографиями.

## Реализованный функционал

- Просмотр общей ленты публикаций.
- Регистрация и авторизация пользователей.
- Добавление публикаций с фотографиями и описанием.
- Просмотр публикаций конкретного пользователя.
- Возможность ставить и снимать лайки.
- Сохранение авторизации после перезагрузки страницы.
- Отображение даты публикации в относительном формате.
- Защита от вставки HTML-кода в пользовательские данные.

15 часов

## Фактически затраченное время

Ориентировочно 20–30 часов, включая изучение кода,
реализацию функциональности, исправление ошибок
и тестирование.
